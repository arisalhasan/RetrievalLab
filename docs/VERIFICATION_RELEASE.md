## Explicit limits

The final official-test study completed six isolated workers, each covering all 300 official test queries and the same 16 label-independent timing IDs with 48 measured calls. Every per-system metric passed its pytrec_eval check. The frozen model choice remained `hybrid-10`; the final downloaded dashboard CSV matched the saved metrics to numerical precision. Source/model/config/data/runtime fingerprints still matched the original pre-test freeze after all runs and browser checks. Final JSON, CSV, Markdown, PNG and SVG exports were generated, and the figure was visually inspected. Additional paired reranker comparisons and the post-test overlap audit are preserved separately. A tab rerun can return to Search; this observed interface limitation and recovery are documented in the runbook.

No model code or experiment settings changed after first official test access. The final documentation also reports overlap in the official split: 157 test claims share positive evidence with the 647 training claims, and 61 have token-Jaccard similarity at least 0.8 to a training claim. This descriptive audit did not change selection or training.

The full SciFact training experiment was not independently repeated. Historical M3–M5 validation experiments include their own documented repetitions; that does not imply a repeated final training or test study. The tiny synthetic training integration test verifies the mechanics separately and is not a benchmark score.

GPU execution, macOS/Linux, fresh-machine installation, external/public hosting, production concurrency/load, internet-facing security, clinical use, and million-document scale were not tested. GitHub Actions was authored but not run on GitHub. No public repository, deployment or external review was created. The full BEIR neural API was not installed/executed; official BEIR SciFact files and pytrec_eval supply the benchmark data and independent metric verification.

Latency is descriptive workstation performance, with background load uncontrolled. RSS is sampled whole-process memory and may miss short peaks. Validation selection is exploratory and has been inspected repeatedly. Unjudged negatives can contain relevant evidence; grouping cannot prove semantic independence; upstream model-training contamination is unaudited. Official test results must not become new model-selection feedback.
